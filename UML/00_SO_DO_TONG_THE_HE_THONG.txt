I. TỔNG QUAN KIẾN TRÚC PHÂN TẦNG ĐA TẦNG (MULTI-TIER LAYERED ARCHITECTURE)
------------------------------------------------------------------------------------------------------------------------
Hệ thống được tổ chức theo mô hình Kiến trúc phân tầng (Layered Architecture) chuẩn mực với nguyên tắc Separation of 
Concerns (Tách biệt các mối quan tâm) và Dependency Inversion Principle (Đảo ngược phụ thuộc - DIP trong SOLID).
Mỗi tầng chỉ giao tiếp với tầng bên dưới qua Interface trừu tượng hoặc Data Entities, không có phụ thuộc vòng tròn:

┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 1: TRÌNH DIỄN GIAO DIỆN NGƯỜI DÙNG (PRESENTATION LAYER - SWING UI & DESKTOP GRAPHICS)                           │
│ Packages: vn.edu.ptit.oop.nhom08.ui, vn.edu.ptit.oop.nhom08.ui.dialogs, ui.panels, common                            │
│ - BaseWindow (Template Method Pattern) -> MainWindow (JFrame điều phối chính 2 Tab: Hồ sơ & Bảng lương)              │
│ - EmployeeFormDialog (CardLayout đa hình nhập liệu), AboutDialog (Thông tin đồ án), ChartWindow (JFreeChart)         │
│ - EmployeeTableModel & PayrollTableModel (kế thừa AbstractTableModel), PayrollCellRenderer (Kẻ sọc, căn tiền)        │
│ -> VAI TRÒ: Nhận tương tác chuột/phím, điều hướng giao diện, cập nhật đồ họa trên Event Dispatch Thread (EDT).       │
│    Tuyệt đối không chứa công thức tính thuế, tính lương hay logic đọc/ghi tệp CSV trực tiếp.                         │
└──────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────────┘
                                                           │ (Bơm Repository / Gọi Service qua Interface)
                                                           ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 2: NGHIỆP VỤ & TÍNH TOÁN TÀI CHÍNH DOANH NGHIỆP (SERVICE LAYER - BUSINESS LOGIC)                                │
│ Package: vn.edu.ptit.oop.nhom08.service                                                                              │
│ - PayrollService: Tính tổng quỹ lương gộp, tổng thuế TNCN, tổng thực lĩnh, phân bổ chi phí phòng ban, min/max/avg.   │
│ -> VAI TRÒ: Đóng gói toàn bộ logic tài chính độc lập, ứng dụng Java 8 Stream API (Filter, MapToDouble, Reduce).      │
│    Giao tiếp với Tầng dữ liệu hoàn toàn qua Interface EmployeeRepository (Constructor Dependency Injection).         │
└──────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────────┘
                                                           │ (Truy xuất qua Interface EmployeeRepository)
                                                           ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 3: TRUY XUẤT & ĐỒNG BỘ DỮ LIỆU (REPOSITORY LAYER - DATA ACCESS OBJECT & STORAGE ENGINE)                         │
│ Package: vn.edu.ptit.oop.nhom08.repository                                                                           │
│ - <<interface>> EmployeeRepository: Bản hợp đồng công bố 15 phương thức CRUD, backup, restore, sync.                 │
│ - InMemoryEmployeeRepository: Quản lý lưu trữ kép Dual-Level Storage (RAM LinkedHashMap O(1) + File CSV vật lý).     │
│ -> VAI TRÒ: Trừu tượng hóa việc lưu trữ, cách ly hoàn toàn tầng trên khỏi định dạng tệp CSV và bộ nhớ đệm RAM.       │
└──────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────────┘
                                                           │ (Thao tác trên các thực thể thế giới thực)
                                                           ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 4: THỰC THỂ CỐT LÕI & CHÍNH SÁCH THUẾ TNCN (DOMAIN MODEL LAYER - BUSINESS ENTITIES)                             │
│ Package: vn.edu.ptit.oop.nhom08.model                                                                                │
│ - <<abstract>> Employee: id, fullName, department, baseSalary, hireDate, calculateSalary()*, getRoleName()*          │
│ - FullTimeEmployee (Lương hệ số + Thưởng), Manager (Kế thừa 2 tầng), PartTimeEmployee (Lương giờ), Intern (Trợ cấp)  │
│ - <<interface>> Taxable: calculateTax() | TaxCalculator: Bảng 4 bậc thuế thu nhập cá nhân lũy tiến từng phần tĩnh    │
│ -> VAI TRÒ: Đại diện cho các đối tượng thực tế và quy tắc kinh doanh bất biến của doanh nghiệp.                      │
└──────────────────────────────────────────────────────────▲───────────────────────────────────────────────────────────┘
                                                           │ (Bổ trợ kỹ thuật xuyên suốt hệ thống)
┌──────────────────────────────────────────────────────────┴─────────────────────────────────────────────────────────┐
│ TẦNG TIỆN ÍCH DÙNG CHUNG & BẢO VỆ DỮ LIỆU (CROSS-CUTTING CONCERNS - UTILITIES & EXCEPTIONS)                        │
│ Packages: vn.edu.ptit.oop.nhom08.util & vn.edu.ptit.oop.nhom08.exception                                           │
│ - CurrencyFormatUtil: Định dạng tiền tệ VNĐ (#,##0 VNĐ) và ngày tháng chuẩn Việt Nam (dd/MM/yyyy).                 │
│ - EmployeeComparator: Chiến lược sắp xếp đa tiêu chí (Strategy Pattern), hỗ trợ tiếng Việt chuẩn qua Collator.     │
│ - ChartHelper & DeptSummary: Xây dựng biểu đồ cột & biểu đồ tròn thống kê JFreeChart.                              │
│ - PayslipExporter: Xuất phiếu lương cá nhân chi tiết và bảng lương toàn doanh nghiệp ra Text, HTML, CSV.           │
│ - InvalidEmployeeDataException: Ngoại lệ kiểm soát tính hợp lệ dữ liệu nhập vào toàn hệ thống.                     │
│ - Main: Điểm vào của chương trình, nạp FlatLightLaf Look and Feel và khởi chạy trên luồng EDT.                     │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

IV. CÁC LUỒNG TƯƠNG TÁC XUYÊN TẦNG ĐIỂN HÌNH (CROSS-LAYER INTERACTION FLOWS)
------------------------------------------------------------------------------------------------------------------------

1. LUỒNG KHỞI ĐỘNG HỆ THỐNG (STARTUP SEQUENCE):
   Main.java
     │── (1) FlatLightLaf.setup() -> Thiết lập giao diện FlatLaf hiện đại
     │── (2) SwingUtilities.invokeLater() -> Đẩy tiến trình khởi dựng lên luồng Event Dispatch Thread (EDT)
     │── (3) new InMemoryEmployeeRepository() -> Khởi tạo tầng dữ liệu
     │         │── (3.1) loadFromCsv("data/employees.csv") -> Đọc tệp phẳng CSV
     │         └── (3.2) Parse từng dòng -> Tạo đối tượng FullTime/PartTime/Intern/Manager nạp vào LinkedHashMap
     │── (4) new PayrollService(repository) -> Bơm phụ thuộc Repository vào tầng Nghiệp vụ (Dependency Injection)
     └── (5) new MainWindow(repository, payrollService) -> Khởi tạo màn hình chính
               │── (5.1) super() -> BaseWindow.setupWindow() (Áp dụng Template Method Pattern)
               └── (5.2) initUI() -> Dựng Tab 1 (Hồ sơ), Tab 2 (Tính lương), nạp dữ liệu lên JTable

2. LUỒNG THÊM MỚI NHÂN VIÊN ĐA HÌNH (CREATE EMPLOYEE SEQUENCE):
   Người dùng click nút "Thêm nhân viên" trên thanh công cụ MainWindow
     │── (1) MainWindow mở hộp thoại modal: new EmployeeFormDialog(this, repository)
     │── (2) Người dùng chọn loại nhân sự trên JComboBox (Toàn thời gian / Bán thời gian / Thực tập sinh / Quản lý)
     │         └── Dialog sử dụng CardLayout lật đúng panel chứa các trường dữ liệu đặc thù
     │── (3) Người dùng nhập liệu và bấm "Lưu":
     │         │── (3.1) Kiểm tra tính hợp lệ -> Ném InvalidEmployeeDataException nếu vi phạm ràng buộc
