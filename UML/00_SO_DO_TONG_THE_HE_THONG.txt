I. TỔNG QUAN KIẾN TRÚC PHÂN TẦNG (LAYERED ARCHITECTURE)
----------------------------------------------------------------------------------------------------
Hệ thống được thiết kế theo mô hình Kiến trúc phân tầng (Layered Architecture) chuẩn mực với nguyên tắc
"Separation of Concerns" (Tách biệt các mối quan tâm) và "Dependency Inversion Principle" (Đảo ngược phụ
thuộc trong SOLID). 

Mỗi tầng chỉ giao tiếp với tầng liền kề bên dưới thông qua các Giao diện trừu tượng (Interface) hoặc 
đối tượng truyền tải dữ liệu (Data Entities), hoàn toàn không có sự phụ thuộc vòng tròn (Circular Dependency):

┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 1: TRÌNH DIỄN GIAO DIỆN NGƯỜI DÙNG (PRESENTATION LAYER - SWING UI)                          │
│ Package: vn.edu.ptit.oop.nhom08.ui, vn.edu.ptit.oop.nhom08.ui.dialogs, ui.panels, common         │
│ - BaseWindow (Template Method) -> MainWindow (JFrame điều phối chính 2 Tab)                      │
│ - EmployeeFormDialog (CardLayout đa hình), AboutDialog, ChartWindow (JFreeChart)                 │
│ - EmployeeTableModel, PayrollTableModel (AbstractTableModel), PayrollCellRenderer                │
│ -> VAI TRÒ: Thu nhận sự kiện chuột/phím, điều hướng giao diện, cập nhật đồ họa trên EDT.         │
│    Tuyệt đối không chứa công thức tính thuế, tính lương hay logic đọc/ghi tệp CSV trực tiếp.     │
└────────────────────────────────────────────────┬─────────────────────────────────────────────────┘
                                                 │
                                                 │ (Gọi nghiệp vụ / Bơm Repository)
                                                 ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 2: NGHIỆP VỤ & TÍNH TOÁN TÀI CHÍNH (SERVICE LAYER)                                          │
│ Package: vn.edu.ptit.oop.nhom08.service                                                          │
│ - PayrollService: Tổng quỹ lương, tổng thuế, phân bổ chi phí phòng ban, thống kê min/max/avg.    │
│ -> VAI TRÒ: Xử lý toàn bộ logic tính toán tài chính độc lập, ứng dụng Java 8 Stream API.         │
│    Giao tiếp với Tầng dữ liệu qua Interface EmployeeRepository (Constructor Injection).          │
└────────────────────────────────────────────────┬─────────────────────────────────────────────────┘
                                                 │
                                                 │ (Truy xuất qua Interface EmployeeRepository)
                                                 ▼
┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│ TẦNG 3: TRUY XUẤT & ĐỒNG BỘ DỮ LIỆU (REPOSITORY LAYER - DATA ACCESS OBJECT)                      │

IV. CÁC LUỒNG TƯƠNG TÁC XUYÊN TẦNG ĐIỂN HÌNH (CROSS-LAYER INTERACTION FLOWS)
----------------------------------------------------------------------------------------------------

1. LUỒNG KHỞI ĐỘNG HỆ THỐNG (STARTUP SEQUENCE):
   Main.java
     │── (1) FlatLightLaf.setup() -> Cài đặt giao diện FlatLaf hiện đại
     │── (2) SwingUtilities.invokeLater() -> Đẩy tiến trình lên Event Dispatch Thread (EDT)
     │── (3) new InMemoryEmployeeRepository() -> Khởi tạo tầng dữ liệu
     │         │── (3.1) loadFromCsv("data/employees.csv") -> Đọc tệp phẳng CSV
     │         └── (3.2) Parse từng dòng CSV -> Tạo đối tượng FullTime/PartTime/Intern/Manager nạp vào RAM Map
     │── (4) new PayrollService(repository) -> Bơm phụ thuộc Repository vào tầng Nghiệp vụ
     └── (5) new MainWindow(repository, payrollService) -> Khởi tạo giao diện chính
               │── (5.1) super() -> Gọi BaseWindow.setupWindow() (Template Method)
               └── (5.2) initUI() -> Dựng Tab 1 (Hồ sơ), Tab 2 (Lương), nạp dữ liệu lên JTable

2. LUỒNG THÊM MỚI NHÂN VIÊN ĐA HÌNH (CREATE EMPLOYEE SEQUENCE):
   Người dùng click nút "Thêm nhân viên" trên MainWindow
     │── (1) MainWindow mở hộp thoại: new EmployeeFormDialog(this, repository)
     │── (2) Người dùng chọn loại nhân viên trên ComboBox (FullTime, PartTime, Intern, Manager)
     │         └── Dialog dùng CardLayout lật đúng panel nhập liệu đặc thù
     │── (3) Người dùng nhập thông tin và bấm "Lưu":
     │         │── (3.1) Kiểm tra tính hợp lệ (Validate) -> Ném InvalidEmployeeDataException nếu vi phạm
     │         └── (3.2) Tạo đúng thể hiện cụ thể: Employee newEmp = new Manager(...) / FullTime(...)
     │── (4) repository.save(newEmp)
     │         │── (4.1) Kiểm tra trùng lặp ID trên RAM Map: storage.containsKey(id)
     │         │── (4.2) Lưu vào LinkedHashMap: storage.put(id, newEmp)
     │         └── (4.3) Ghi nối tiếp (Append) dòng mới ra file CSV vật lý: data/employees.csv
     └── (5) MainWindow.applyFilterAndSort() -> Tự động nạp lại TableModel và vẽ lại bảng

3. LUỒNG TÍNH LƯƠNG & XUẤT PHIẾU LƯƠNG TOÀN DOANH NGHIỆP:
   MainWindow chuyển sang Tab 2 "Bảng Tính Lương & Thuế TNCN"
     │── (1) PayrollTableModel duyệt qua danh sách Employee từ Repository
     │── (2) Với mỗi nhân viên 'e', gọi 'e.calculateSalary()' -> Đa hình lúc chạy (Dynamic Binding)
     │── (3) Nếu 'e instanceof Taxable', gọi '((Taxable) e).calculateTax()' -> Tính thuế TNCN
     │── (4) Tính Thực lĩnh = Lương tổng - Thuế TNCN
     │── (5) Cập nhật các ô tóm tắt trên ToolBar:
     │         │── payrollService.calculateTotalPayroll()
     │         │── payrollService.calculateTotalTax()
     │         └── payrollService.calculateTotalNetPay()
     └── (6) Người dùng chọn 1 nhân viên và bấm "Xuất phiếu lương":
               └── PayslipExporter.exportToHtml(emp, targetFile) -> Sinh mã HTML xuất sắc ra đĩa
